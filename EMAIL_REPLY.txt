=========================================
LOCAL SETUP INSTRUCTIONS (LARAVEL)
=========================================
1. Clone the repository & install dependencies:
   git clone https://github.com/hrshanto807/doctor-tracker.git
   cd doctor-tracker
   composer install

2. Configure environment & SQLite database:
   cp .env.example .env
   php artisan key:generate
   touch database/database.sqlite
   php artisan migrate:fresh --seed

3. Start the local server:
   php artisan serve
   (Access locally at: http://127.0.0.1:8000)

4. Run automated test suite:
   php artisan test
   (All 8 test cases pass with 27 assertions)
